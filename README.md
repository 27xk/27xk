## 🚀 正在折腾的项目方向

### XiaoAI 智能音箱控制平台

面向小爱音箱的一套智能控制与消息处理平台，重点是把设备控制、消息监听、AI 对话和工具调用整合到一个稳定的后端服务中。

**主要内容：**

- 对接小米 `MiIOT / MiNA` 私有协议通信流程
- 实现设备控制、消息监听、任务调度与异常重试
- 使用 `Redis + WebSocket` 支撑实时通信与状态同步
- 集成 LLM 对话、MCP 工具调用、记忆管理能力
- 处理 `RC4` 加密、`SHA-256` 签名、Token 自动刷新等流程

> 这个项目更偏向 **后端服务 + 协议分析 + 自动化执行 + AI 工具调用** 的组合实践。

---

### GateMesh API 服务平台

一个面向接口能力管理的后端平台构想，用来把逆向、自动化、登录流程、加密逻辑等脚本能力统一封装成可管理的 API 服务。

**核心设计：**

- 后台可动态添加 API 接口
- 每个接口可绑定一个 Python 插件文件
- 支持配置依赖库、请求参数、执行逻辑和返回结构
- 用户通过自己的 Key 调用接口
- 后台统计调用次数、权限状态和余额消耗
- 免费接口默认开放，收费接口按权限和余额控制访问

> 目标不是只做接口文档，而是把“能跑的脚本”变成“可管理、可调用、可复用的服务能力”。

---

### qvtool / App 调试工具链

围绕 QQ、微信等 App 的本地调试与接口封装工具，主要用于辅助协议分析、参数定位、消息链路调试和自动化能力验证。

**主要关注：**

- Android Runtime Hook 与多进程环境适配
- QQ / 微信消息链路调试
- 网络请求参数定位与数据结构分析
- 本地 HTTP / MCP 调试服务封装
- 通过插件化方式沉淀可复用能力
